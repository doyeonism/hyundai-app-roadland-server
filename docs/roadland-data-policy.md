# 로드랜드 데이터와 정산 정책

## 수집과 보관
원본 GPS 좌표는 서버에 전송하지 않는다. 약 10m 규모의 타일 식별자도 생활 동선을 추정할 수 있는 데이터로 취급한다.
주행별 타일 상세는 90일 후 비우고, 날짜별 방문은 서울 기준 최근 7일만 유지한다.
구매 자격 및 재방문 판정을 위해 날짜 목록 없는 방문 타일과 마지막 통과 시각은 계정 삭제까지 보관한다.
중복 정산 키, 주행 요약, 크레딧 원장은 정산 일관성을 위해 계정 삭제까지 유지한다.
사용자 DELETE /api/roadland/v1/car/profile은 차량과 종속 DB 데이터를 삭제하고 인증 캐시와 랭킹을 정리한다.
백업 파일에 대한 별도 보존·만료 정책은 운영 배포 전에 확정해야 한다.

## 정산
차량별 Redis 잠금과 DB SELECT FOR UPDATE를 함께 사용한다. 구매 시 양쪽 차량을 ID 순서로 잠근다.
동일 차량의 다른 주행이 시간상 겹치면 overlap으로 기록하고 보상·방문 자격을 부여하지 않는다.
서울 기준 주행 종료 날짜의 TRIP 원장 합계로 일일 상한을 계산한다. 원장의 settlement_day를 별도로 저장하여 실제 원장 생성 시각과 정산 날짜를 구분한다.
개인 레벨업은 보유 잔액으로 결제하고 기존 레벨의 누적 수익을 지급한 뒤 레벨을 올린다. 누적 수익만으로 결제하려면 먼저 수령한다.
땅 랭킹은 레벨 합이 아니라 소유한 땅 수다. 기존 owned_tiles.level은 과거 데이터 호환용으로만 남긴다.

## 시연과 운영
NODE_ENV=production에서는 개발 라우트를 등록하지 않고 게임 시간 가속도 비활성화한다.
스테이징은 ROADLAND_DEV_TOOLS=true와 ROADLAND_DEV_TOKEN을 함께 설정하고 x-roadland-dev-token 헤더로 인증한다.
development/test에서만 인증키 없는 로컬 개발 도구를 허용한다. 개발 서버를 외부 공개하지 않는다.

## 외부 확인이 필요한 항목
Pleos 차량 고유 ID·계정 연동·기기 검증 API 지원 여부와 재설치 시 복구 정책.
특별 구간과 별도 지갑 테이블은 현재 기능에 필수이지 않아 도입하지 않는다.
